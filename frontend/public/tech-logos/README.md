# Логотипи технологій — тепер НЕ тут

З 2026-10-17 логотипи живуть у хмарі (R2, бакет фото), а не в репозиторії:

- **Майстер:** локальна тека `~/Downloads/Бізнес/Лого/` — `Технології/<група>/` (Мембрани,
  Підошви, Матеріали…), а також `Магазин/` та `Іконки/`; опис усього — `manifest.json`.
- **Хмара:** `logos/<той самий шлях>` (оригінали) і `logos/web/<шлях>` — зменшені копії
  для вітрини (2–5 КБ), які генеруються з майстра.
- Вітрина отримує список із `/api/config` (`tech_logos`, бекенд читає маніфест з R2) і
  зіставляє технологію з лого за слагом (`frontend/src/techLogos.ts`) або аліасом з маніфесту.

Нове лого: покласти файл у відповідну групу майстра, додати запис у `manifest.json`
(slug, label, group, file, aliases) і залити теку в R2. Поки лого немає — показується
текстовий бейдж (нічого не ламається).
